# Aditya & Siddhibala Wedding Invitation

Standalone Hindi website based on source project _3.

- Published URL: https://adityadubey1313-oss.github.io/adisiddhi_6/
- Language: Hindi only; there is no language switch.
- Features: the traditional invitation and family lineage, six events, Hotel Gulzar directions, contacts, and WhatsApp sharing. No separate family section or calendar button is included.
- Assets: relative paths keep this package portable at its repository root.
- Deployment: `.github/workflows/adisiddhi.yml` publishes this directory to GitHub Pages from the parent repository.

The package uses relative asset paths and can also be published from its own repository root at the URL above.
