# Aditya & Siddhibala Wedding Invitation

Standalone Hindi website based on source project _2.

- Published URL: https://adityadubey1313-oss.github.io/adisiddhi_2h/
- Language: Hindi only; there is no language switch.
- Features: Hotel Gulzar, the extended family roster, venue directions, contacts, and WhatsApp sharing. The page intentionally omits schedule and calendar controls.
- Assets: relative paths keep this package portable at its repository root.
- Deployment: the repository-local workflow at .github/workflows/deploy-pages.yml publishes this package root to GitHub Pages.

Push this package as the root of its own repository to publish it at the URL above.
